# Emojis

Custom hand-drawn pixel emojis used in Roomgather's emoji picker.

**Naming convention:** `rg_<shortcode>.png` (e.g., `rg_heart.png` for `:heart:`).
**Usage:** Referenced from `script.js` via the `customEmojis` array.
**Adding a new emoji:** Add the PNG here + an entry in the `customEmojis` array + a Unicode mapping in `renderCustomEmojis`.
